# Random Snake Obstacles Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add eight fair, randomly regenerated obstacles to the self-contained Snake game and make obstacle collisions end the game.

**Architecture:** Keep all behavior in `snake.js`. Store obstacles as tile coordinates, generate them after the starting snake is initialized, reuse a shared occupancy check for obstacle-aware food placement, and include obstacle occupancy in the existing movement collision gate.

**Tech Stack:** Plain JavaScript, HTML Canvas, browser file URL, Node.js syntax checker.

## Global Constraints

- Obstacles are single tiles and eight are generated per game start.
- Obstacles cannot overlap the starting snake.
- Food cannot overlap obstacles or the snake.
- Obstacle collisions use the existing game-over overlay and restart flow.
- Do not change controls, score rules, board dimensions, or dependencies.

### Task 2: Add random obstacle generation and collision

**Files:**
- Modify: `snake.js`

**Interfaces:**
- Consumes: `snake`, `food`, `tileCount`, `drawGame`, and `endGame`.
- Produces: an `obstacles` array of `{ x, y }` positions regenerated by `startGame` and checked by `updateGame`.

- [ ] **Step 1: Add the obstacle state and occupancy helpers**

Add `obstacleCount = 8`, a mutable `obstacles` variable, and helpers that identify whether a tile is occupied by the snake or an obstacle. Generate unique random obstacle positions after initializing the starting snake, rejecting any snake tile or previously selected obstacle.

- [ ] **Step 2: Make food placement avoid obstacles**

Update `placeFood()` so its random candidate is rejected when it overlaps either the snake or an obstacle.

- [ ] **Step 3: Include obstacles in movement collision**

Compute `hitObstacle` from the proposed head position and call `endGame()` when it is true alongside wall and snake collisions.

- [ ] **Step 4: Render obstacles**

Draw every obstacle tile after clearing the board and before drawing food and snake, using a contrasting color and leaving a one-pixel gap consistent with snake segments.

Expected: PASS.

Then reload the browser page and perform the checks from Task 1, including multiple restarts and an obstacle collision.
